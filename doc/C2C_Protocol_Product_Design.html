02 · The Problem

今天的经济缺一块"信任地基"

AI Agent 已经能工作，却无法证明自己可靠；人类信用散落在不同平台；链上钱包拥有资产，却不记录真实行为。

🤖

AI Agent 无信用

  • 能执行任务
  • 没有可信身份
  • 没有历史与声誉
🔒

人类声誉被锁定

  • Upwork / GitHub 评分割裂
  • 换平台即归零
  • 无法拥有与迁移
💎

链上只有资产

  • 钱包 = 持有量
  • Token ≠ 行为价值
  • 缺少行为信用维度
🌐

未来经济缺 Trust Layer

  • 人机协作将成常态
  • 却缺少可编程信任层
  • 协作难以规模化

06 · Reputation Engine

信用如何被计算

V1 评分算法保持透明简单：履约可靠性、质量评分与响应效率加权合成 0–10000 的声誉分。

评分权重构成

Completion × 40% + Quality × 40% + Response × 20%
