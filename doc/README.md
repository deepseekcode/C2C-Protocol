## 原型说明

`C2C_Protocol_Product_Design.html` 为单文件产品设计页面：

- **图表库**：Chart.js / ECharts / mermaid，均走 CDN，**打开需联网**（离线时各图表区域会显示降级提示，页面其余内容不受影响）
- **包含**：产品愿景、问题、四层协议架构、人机经济飞轮（桑基图）、Agent 信用生命周期、信用引擎（评分权重/画像雷达）、合约架构图、数据生命周期、体系指标（MVP 目标/增长预测）、生态用户/商业模式、Avalanche 选型、路线图
- 页内数据均为**产品设计示意**，不代表真实运营数据

- 修改实施计划/Builder Hub 方案 → `实施方案.md`
